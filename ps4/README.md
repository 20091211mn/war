# نسخة PS4 (تجريبية — homebrew على جهاز مكسور الحماية)

الحزمة تحتوي خادم HTTP صغيرًا (C، OpenOrbis) يقدّم صفحة اللعبة المدمجة على المنفذ 8080 ثم يطلب فتح متصفح PS4 على `http://127.0.0.1:8080`.
- اللعب المنفرد ضد البوتات يعمل بالكامل داخل الصفحة.
- يد PS4: عصا يسار = حركة، يمين = نظر، R2 نار، L2 تصويب، X قفز، O انحناء، □ تذخير، △ تبديل، R1 قنبلة، L1 استخدام، L3 عدْو، Options إيقاف.
- إن لم يفتح المتصفح تلقائيًا: افتح متصفح PS4 يدويًا واكتب العنوان أعلاه.
البناء: تبويب Actions ← Build PKG (ps4.yml). الملف الناتج: Warzone-ps4-pkg.
