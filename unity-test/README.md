# Warzone — تجربة Unity

لعبة تجريبية بسيطة (فريقان أحمر/أزرق، 10 بوتات، حركة وإطلاق وتعبئة). العالم كله يُبنى بالكود عند التشغيل.

## التشغيل
1. Unity Hub ← Add project from disk ← هذا المجلد (`unity-test`). الإصدار 2022.3 LTS أو أحدث (يقبل Unity 6).
2. من القائمة العليا: **Warzone ← Setup Scene and Android** (مرة واحدة).
3. اضغط **Play**. (إن ظهر خطأ Input: Edit ← Project Settings ← Player ← Active Input Handling = **Both**).
4. حاسوب: WASD + ماوس، Shift ركض، Space قفز، R تعبئة. جوال: عصا يسار، سحب يمين للنظر، زر FIRE وR.

## بناء Android
File ← Build Settings ← Android ← Build (يتطلب Android Build Support في Hub).

> لم يُجرَّب داخل Unity (لا يوجد Unity في بيئة العمل)؛ إن ظهر خطأ برمجي أرسله وأُصلحه.
