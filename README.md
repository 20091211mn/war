# Warzone — حرب فرق 3D للجوال (أحمر ضد أزرق)

تطبيق أندرويد حقيقي (APK) تعمل فيه اللعبة كاملة **داخل التطبيق بدون إنترنت وبدون أي موقع**.
الشبكة المحلية (LAN) **اختيارية**: العب منفردًا ضد البوتات، أو استضف غرفة لأصدقائك من داخل التطبيق، أو انضم لغرفة صديق.

## ما الجديد
- **قائمة رئيسية**: «العب منفردًا» / «استضف لعبة شبكة محلية» / «انضم إلى لعبة شبكة محلية». لا يوجد إدخال عنوان موقع.
- **استضافة LAN من داخل التطبيق** (إضافة أندرويد أصلية): الأصدقاء يجدونك بالبحث التلقائي. الانضمام من تطبيق أندرويد أو PS4 فقط (لا نسخة ويب).
- **مرحلة صحراء الشاص** (5 خرائط الآن): 6 سيارات شاص تويوتا، قيادة بفيزياء حقيقية (تسارع، انزلاق، فرامل يد، انحراف عند انفجار إطار)،
  ركاب في الأمام والصندوق يطلقون النار (الراكب الأمامي يميل خارج النافذة)، الركاب يُصابون ويُقتلون، إطارات تنفجر بالرصاص، السيارة تشتعل ثم تنفجر
  وتقتل من بداخلها وتؤذي من حولها، دهس، تصادمات، خزان وقود ضعيف. تعيد الظهور بعد 30 ثانية. الخريطة فيها خنادق وصخور وقرية وحقل نفط وأماكن اختباء.
- **شخصيات ثلاثية الأبعاد أفضل**: خوذة ونظارة وسترة ودروع وحقيبة وقفازات وأحذية، وضعية جلوس في السيارة.
- **أصوات**: محرك سيارة مستمر، انفجار إطار، تصادم، انزلاق، التقاط ذخيرة، رسائل الدردشة.
- **اللوبي**: دردشة (عامة/فريق)، صلاحيات المضيف: الخريطة، حد النقاط، الوقت، عدد/ذكاء البوتات، زمن الإحياء، المركبات، النيران الصديقة، تجدد الصحة، خلط الفرق، نقل لاعب، طرد، نقل الإدارة.
- **أثناء المباراة**: المضيف يغيّر الخريطة ويعيد المباراة من قائمة الإيقاف. عند انتهاء المباراة يعود **الجميع معًا إلى اللوبي**.
- **الموت**: لوحة لتغيير السلاح (أرقام 1–8) وتعديل الملحقات، ثم تظهر عند نقطة فريقك خلال الزمن المحدد.
- **شريط صحة حقيقي**: مقاطع، شريط شبح يتأخر عند الضرر، نبض عند الصحة المنخفضة، تجدد تلقائي بعد 6 ثوانٍ بلا إصابة.
- **ذخيرة الأعداء**: عند قتل لاعب تسقط ذخيرة سلاحيه؛ تلتقطها بالمرور عليها **فقط إذا كان معك نفس السلاح** (تظهر مضيئة).

## التحكم
- **جوال**: عصا يسار، اسحب يمين للنظر، أزرار النار/التصويب/القفز/الانحناء/التلقيم/التبديل/القنبلة. قرب سيارة يظهر زر **الركوب**؛ داخلها: تبديل المقعد، الكاميرا، والقفز = فرامل اليد. الدردشة بزر الفقاعة.
- **كمبيوتر**: WASD، ماوس، يمين تصويب، Shift ركض، C انحناء، Space قفز (فرامل يد أثناء القيادة)، R تلقيم، 1/2/Q تبديل، G قنبلة،
  **E ركوب/نزول، F تبديل المقعد، V الكاميرا**، Enter/T دردشة، Tab النتائج، Esc إيقاف.

## بناء الـ APK (بدون Android Studio)
1. ارفع المشروع إلى مستودعك على GitHub (الأوامر بالأسفل).
2. تبويب **Actions** ← «Build Android APK» (نحو 5–8 دقائق؛ يعمل بـ Node 22).
3. حمّل `app-debug.apk` من **Releases ← Warzone (APK)** وثبّته.

```sh
git init && git add . && git commit -m "Warzone"
git branch -M main
git remote add origin https://github.com/<حسابك>/war.git
git push -u origin main
```

## التشغيل على Termux / كمبيوتر (خادم مستقل، اختياري)
```sh
node server/server.js
```
ثم انضم من تطبيق Warzone (أندرويد) أو من PS4. لا توجد نسخة ويب: الخادم لا يقدّم صفحة لأي متصفح.

## الاختبارات
`npm test` (Node 22): الخرائط والسلالم، منطق المركبات/الدردشة/المضيف/الذخيرة، والخادم الكامل (12 لاعبًا).
اختبارات المتصفح (Playwright) في `test/test-browser.mjs` و`test/test-app-mode.mjs`.
