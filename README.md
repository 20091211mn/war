# Warzone LAN — حرب فرق 3D للجوال (أحمر ضد أزرق)

لعبة تصويب من منظور الشخص الأول، فريقان (أحمر/أزرق)، **4 خرائط**، **8 أسلحة** مع ملحقات (منظار، كاتم، مقبض/ليزر، مخازن)،
قنابل يدوية، بوتات اختيارية، ودعم حتى **16 لاعبًا** عبر الشبكة المحلية (LAN / هوتسبوت).
تعمل من **المتصفح** على أندرويد وآيفون (وأي كمبيوتر). **لا تحتاج أي مكتبات** (بدون npm install).

## التشغيل على Termux (أندرويد = الخادم)
```sh
pkg update && pkg install -y nodejs git
git clone https://github.com/<حسابك>/warzone-lan.git
cd warzone-lan
./start.sh          # أو: node server/server.js
```
سيطبع الخادم عنوانًا مثل `http://192.168.1.5:3000`.
- افتحه أنت وأصدقاؤك في Chrome/Safari (نفس شبكة الواي فاي، أو شغّل هوتسبوت من جهاز المضيف).
- لو لم يظهر العنوان: اكتب `ifconfig` أو `ip addr` وابحث عن 192.168.x.x.
- لا تغلق Termux (يُفضّل `termux-wake-lock`، ويُفعَّل تلقائيًا عبر start.sh إن توفّر Termux:API).
- آيفون: يدخل كلاعب عبر Safari (لا يمكن أن يكون الخادم). «مشاركة ← إضافة إلى الشاشة الرئيسية» لملء الشاشة.

## تطبيق أندرويد (APK)
يُبنى التطبيق تلقائيًا على GitHub (لا تحتاج Android Studio):
1. ارفع المشروع إلى مستودعك (الخطوات بالأسفل).
2. افتح المستودع ← تبويب **Actions** ← انتظر نجاح «Build Android APK» (نحو 5–8 دقائق).
3. حمّل `app-debug.apk` من **Releases ← Warzone LAN (APK)** أو من Artifacts، ثبّته على الهاتف (اسمح بالتثبيت من مصدر غير معروف).
- التطبيق يفتح مباشرة على شاشة **الاتصال بالشبكة المحلية**: بحث تلقائي عن الألعاب، أو إدخال العنوان يدويًا، مع حفظ آخر اتصال.
- المضيف يشغّل الخادم (Termux أو كمبيوتر)، والجميع (بمن فيهم المضيف) يدخلون من التطبيق.
- آيفون: لا يمكن بناء/تثبيت تطبيق بدون Mac وحساب مطوّر Apple؛ استخدم Safari ثم «إضافة إلى الشاشة الرئيسية» فيعمل كتطبيق بملء الشاشة.

## رفع المشروع إلى GitHub
```sh
cd warzone-lan
git init && git add . && git commit -m "Warzone LAN"
git branch -M main
git remote add origin https://github.com/<حسابك>/warzone-lan.git
git push -u origin main
```

## اللعب
- أول من يدخل هو المضيف: يختار الخريطة/الحد/الوقت/البوتات ثم «ابدأ».
- **جوال:** عصا يسار للحركة (ادفعها للنهاية = ركض)، اسحب يمين للنظر، 🔥 نار، 🎯 تصويب، ⤒ قفز، ⤓ انحناء، ↻ تلقيم، ⇄ تبديل، 💣 قنبلة.
- **كمبيوتر:** WASD، ماوس، زر يمين تصويب، Shift ركض، C انحناء، Space قفز، R تلقيم، 1/2 أو Q تبديل، G قنبلة، Tab النتائج، Esc إيقاف.
- تكتيك واقعي: ارتداد وانتشار يتأثران بالحركة/الركض/القفز/الانحناء، تناقص الضرر بالمسافة، ضربات الرأس ×، الركض يمنع الرماية، صوت الخطوات (الانحناء صامت)، الكاتم يخفي إطلاقك عن الرادار، النيران الصديقة معطّلة، حماية ظهور ثانيتين.
